## 维护约定

1. **改动前先读 `PROJECT_NOTES.md`** —— 里面记着已踩过的坑（表格里点括号被 `runTx` 吞掉、
   回调里做字段校验会崩进程、切大类回填要排除当前字段、测试文件里不要用括号定位插入点…）。
2. **改完按 `PROJECT_NOTES.md` 的测试口径跑一遍回归**，数字对不上就别发布。
3. **发布前后**：见 `PROJECT_NOTES.md` 的「当前状态」一节（含那条每次都会出现的误报）。
4. **新增一轮工作**时：在 `DEV_LOG/YYYY-MM-DD.md` 追加当天流水，
   并把稳定的结论沉淀进 `PROJECT_NOTES.md`。
